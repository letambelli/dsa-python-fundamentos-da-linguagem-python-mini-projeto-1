# Mini Projeto 1

Realização do Mini Projeto 1 do curso *Fundamentos de Linguagem Python – Do Básico a Aplicações de IA*, desenvolvido com finalidade de estudo e prática dos conceitos apresentados ao longo do curso.

<br>

# Objetivo

O objetivo desse projeto é refazer o Mini Projeto 1 do curso "Fundamentos de Linguagem Python - Do Básico a Aplicações de IA da DSA" para ter um melhor entendimento das aulas e do conteúdo estudado.

Esse estudo busca realizar as mesmas análises realizadas no projeto original, além de outras análises adicionais.

<br>

## Análise 1 - Top 10 Produtos Mais Vendidos


![Top 10 Produtos Mais Vendidos](./img/grafico%201.png)


A primeira análise proposta se trata dos 10 produtos mais vendidos.

Como a base de dados geradas é diferente da usada pela DSA, os produtos ocupam lugares diferentes dos originais nesse ranking.

Neste caso, o teclado mecânico é o produto mais vendido. O laptop gamer ocupa a segunda posição e o Headset fica em terceiro. A placa de vídeo é o produto menos vendido.

## Análise 4 - Faturamento Por Categoria

![Faturamento Por Categoria](./img/grafico%205.png)

Nesta última análise proposta pela DSA, os produtos são segmentados por categoria, permitindo que o gráfico evidencie o faturamento de cada uma delas.
